# @snk/solver

给定一张贡献热力图（`Grid`）和蛇的初始姿态（`Snake`），算出蛇"吃掉"所有格子的最优路径（`chain: Snake[]`）。

## 目标与约束

- 蛇头每步只能上下左右走一格，且**不能撞到自己身体**（尾巴会同步前移，所以尾格不算撞）。
- 格子按"颜色等级"表示贡献量。蛇只能走到**颜色 ≤ 当前正在清除等级**的格子上；更高等级是暂时不可逾越的"墙"。
- 最终输出是一串连续的蛇姿态，配合渲染层就变成"贪吃蛇吃格子"的动画。

## 核心思路：分层清除

最高效的策略是**从低等级到高等级逐层吃**——低等级格子先清掉后，就变成"可通行"的通道，给后面吃高等级墙腾出空间。对每一层颜色 `color`（`1 → max`）分两个阶段：

### 1. 清除"残留层"（clearResidualColoredLayer）

当 `color > 1` 时，当前要吃的格子比周围某些已清空格子等级高。这些高等级格子被"已清空的低等级区域"包围，蛇如果直接钻进去就出不来了（会撞墙）。因此蛇必须从**网格外部**挖一条隧道（tunnel）进去、再原路返回，且隧道全程不能穿过更高等级的墙。

- `getBestTunnel`：用 A\*（`getSnakeEscapePath`）从目标格出发，找一条"通到外部、且尽量少踩当前颜色"的往返路径；去程和回程分两次搜索以保证能出来。
- `getPriority`：给每条候选隧道打分——优先选"经过的更低色块最多、踩当前颜色最少"的，让低等级区域尽快被消化。
- 每吃掉一条隧道，网格变了，`outside` 与候选隧道列表都会**增量重算并重新排序**，循环直到本层清空。

### 2. 清除"干净层"（clearCleanColoredLayer）

当 `color` 是当前最高（或唯一）等级时，不存在更高等级的墙，蛇在网格内自由穿行即可，无需隧道。这一步直接做**贪心最近邻 BFS**：每次用 BFS 找到最近的同色可达格，走过去吃掉，直到全清。

## 关键辅助：outside 区域

`getBestTunnel` 判断"某格能否从外部免费到达"依赖 `outside`：`outside` 中标记为"外部"的格子 = 蛇不穿过任何 >`color` 的墙就能从网格边界走到的格子。被高等级墙围死的"内袋"不是外部，必须挖隧道。

- `fillOutside`：一次 BFS 泛洪——从网格边界（唯一接触外部的一侧）出发，沿 `grid ≤ color` 的连通区域扩散，把所有"能免费到达"的格子标成外部。等价于原实现"反复全网格松弛到不动点"，但复杂度稳定为 O(W·H)。

## 寻路

- `getPathTo` / `getPathToPose`：A\*（曼哈顿距离启发），用二叉最小堆 `MinHeap` 取最优节点，`Set` 存闭表。
- `getPathToNextPoint`（干净层贪心）：边权恒为 1，退化为 BFS——用 FIFO 队列（O(1) 出队）+ `Set` 闭表，避免原实现 `shift()`/`some()` 的 O(n) 开销。闭表以**整条蛇**（头+身）为键，因为同头不同身的姿态都是合法独立状态。

## 本项目相对原实现的优化（自研点）

在保留上述正确算法的同时，对明显的热点做了有据可查的改写：

1. **干净层 BFS**：`openList.shift()`（O(n) 出队）+ `closeList.some()`（O(n) 查重）→ FIFO 队列（头指针）+ `Set` 闭表，遍历顺序保持一致，输出不变。
2. **fillOutside**：反复全网格松弛 → 单次 BFS 泛洪，结果等价，复杂度从"随口袋数增长的多次全扫描"降为 O(W·H)。
3. **getPriority**：隧道里 `tunnel.findIndex` 的 O(n²) 去重 → `Set` 判首现，语义不变。

所有优化均有 `solver/__tests__`（含 1000 次随机网格 fuzz 校验路径合法性）兜底，保证不改输出。
